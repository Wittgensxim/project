### 解释与结论

P9-1 总表把当前 MVP 的核心结论压缩成四句话：

```text
1. 两个 benchmark set 共 448 个 pair certificate，448/448 reproduced，HardFalseIndependent = 0。
2. static filter after repair 在 Stanford-8 与 Misc8 上都是 StaticFalseNegativeObserved = 0。
3. 两组 depth1 one-swap 都是 16 个 candidate，只有 1 个 `.text` smaller，15 个 IR-different text-equal。
4. 两个 both-smaller program 都能给出 case-level attribution：Queens 和 ffbench。
```

这说明当前最强的阶段性主张不是“找到更优全局 pass order”，而是：

```text
ECPOR 可以用 state-indexed certificates 与高召回 static filter 剪掉大量无需搜索的相邻 pass 顺序；
剩下少数 objective-layer 有收益的 case，可以被压缩成可复查的 attribution evidence。
```

### 风险备注

- P9-1 是汇总，不是泛化证明；benchmark set 仍只有 Stanford-8 与 Misc8。
- Misc8 中 `flops_*` 较多，多样性有限。
- 当前不应把 `both_smaller_cases = 4` 误读为 4 个受益程序；Stanford-8 的 both-smaller programs 仍是 `1`。
- `DirectionAgreementRate` 在 Stanford-8 为 `68.42%`，说明 codegen-path sensitivity 仍然显著。
