### 风险与备注

- `data/outputs/final_mvp_summary/` 仍然按 data retention 规则作为可再生成输出，不纳入 Git 跟踪。

- manifest 指向的是生成它时的 clean commit，而不是包含 manifest 自身的后继提交；这是为了避免“manifest 记录自身”造成不可达的循环版本边界。
