# v0.1.1 ECPOR MVP

This release freezes the 8-pass function-scalar ECPOR MVP after the external clone smoke check.

## Scope

- Stanford-8 + Misc8
- 448 pair certificates
- 448/448 reproduced
- HardFalseIndependent = 0
- StaticFalseNegativeObserved after repair = 0 on both sets
- 32 one-swap candidates
- 2 both-smaller programs
- 2 attribution cases: Queens and ffbench

This is not a complete phase-ordering searcher. It is an evidence-carrying phase-ordering reduction prototype.

## Reproduction Boundary

Fresh clones can inspect:

- `README.md`
- `docs/ecpor_mvp_report.md`
- `docs/results/mvp_summary_manifest.json`

Full `ecpor.mvp_summary` regeneration requires retained local `data/outputs` inputs from the MVP workspace, because generated result artifacts are intentionally not tracked in Git.

The P9-3.6 patch makes missing summary inputs fail explicitly instead of producing an all-zero summary.
